# NG-P2-001 — no time-to-live on last-valid fallback

Classification: `KNOWN_CORE_DEFECT_OPERATIONALLY_MITIGATED`.

The source defect remains present and is not fixed. If a valid seed exists and
the current pricing source becomes stale, invalid, or reverts while the source
trust context still permits the seed, the Stake Ledger can use historical
last-valid evidence without a time-to-live.

The current-generation operational mitigation is to keep
`stakeTargetUsd6 = 20000000` (20 USD) while a spot, ETH/USD, or oracle source is
invalid or last-valid fallback is active. Governance policy says not to modify
that target in this generation. This is an operational policy, not a technical
on-chain immutability guarantee.

This disclosure does not claim the code is fixed, that the policy is immutable,
or that publishing this five-contract subset makes all twelve deployed sources
available.
